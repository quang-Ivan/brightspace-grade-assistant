Brightspace Feedback & Grade Assistant

A blazing-fast userscript for D2L Brightspace. Automatically injects grades and rich rubric feedback from CSV, auto-confirms dialogs, fast-skips already evaluated students, and guarantees 100% class roster coverage with zero missed students.

⚡ 1-Click Install Userscript ⭐ View on GitHub 📥 Download Sample CSV

Why TAs & Instructors Love It

Grading 50–500 students manually on Brightspace takes 15–30 seconds per student. With this script, batch grading a full class takes under 2 minutes.

🔄

Zero-Miss Roster Coverage

Never worry about starting mid-list. When Auto-Cruise starts, it automatically rewinds backward to Student #1 before forward cruising, and wraps around at the end if any students remain unvisited.

📝

True Event Synchronization

Pierces Shadow DOM and TinyMCE iframe editors with Brightspace Siren/Blur event synchronization (d2l-htmleditor-blur), guaranteeing rich HTML feedback is permanently saved to the server.

⚡

0.4s Fast Skip & Dialog Dismissal

Already graded students are skipped in 400ms (while verifying feedback is not blank). Unsaved changes dialogs are dynamically dismissed in 100ms without human intervention.

⚠️

Smart Unsubmitted Handling

Students without homework submissions or missing scores are automatically recognized, alerted on screen, and smoothly skipped to the next student without stalling.

🔒

100% Privacy & FERPA Safe

Zero cloud backend, zero tracking, zero external network calls. All CSV data is read client-side and stored strictly in your browser origin local storage.

🎵

Audio Completion Chime

Synthesizes a pleasant 4-note chime (C5-E5-G5-C6) via the native Web Audio API when all students across the class are 100% graded.

How It Works: 3 Simple Steps

1

Install a Userscript Extension

Install Violentmonkey (recommended) or Tampermonkey in your browser (Chrome, Edge, Firefox, Safari, Brave).

2

Install the Userscript

Click 1-Click Install Script. Your extension manager will open and ask you to confirm. Click Install.

3

Open Brightspace & Start Cruising

Open any student submission evaluation page in Brightspace. The blue assistant panel appears in the bottom right corner. Click 📁 Load Gradebook CSV, pick your file, and click 🚀 Start Auto-Cruise (or press Alt + A)!

Why Start with a CSV File?

Traditional grading forces you to evaluate work and enter data into the LMS at the same time. This userscript decouples the two: you grade offline in your favorite environment (Excel, Google Sheets, Python autograders, or AI grading tools), and the userscript handles 100% of the Brightspace form entry, feedback injection, and navigation automatically.

📊

Workflow 1: Brightspace Export

Go to Grades ➔ Export in Brightspace, select OrgDefinedId (Student ID) and Name fields, and download the roster CSV. Zero manual typing of student names!

📑

Workflow 2: Excel / Google Sheets

Create a simple 3-column sheet (student, score, reason). Leave unsubmitted students blank and export to CSV.

🐍

Workflow 3: Python / Autograder

TAs running Jupyter notebooks or Python test suites can write results directly to a grades.csv with a single loop.

Keyboard Shortcuts

Shortcut Action Description
Alt + A Toggle Auto-Cruise Starts continuous automated grading or pauses execution
Alt + S Emergency Stop Immediately terminates all cruise timers, DOM clicks, and navigation
Alt + H Rewind to First Rapidly rewinds back to Student #1 in the class roster
Alt + F Fill Current Fills grade and feedback for the current student without saving
Alt + → Next Student Navigates to the next student in the iterator
Alt + ← Previous Student Navigates to the previous student in the iterator

Frequently Asked Questions (FAQ)

Does this work with my university's Brightspace domain?
Yes! The script includes universal URL match rules covering *.brightspace.com, *.desire2learn.com, Stony Brook, Purdue, Waterloo, and all custom institutional Brightspace domains.
Will students see feedback immediately?
The script clicks "Save Draft" or "Update", meaning grades and feedback remain in draft mode until you choose to publish them all at once via Brightspace's "Publish All" button.
Is student data protected under FERPA?
Absolutely. The script has zero tracking, zero telemetries, and zero cloud backends. All grading data is processed locally inside your browser and stored in your browser's private origin-isolated storage.
