You did the grading. Let the helper do the typing.

Built for TAs working through assignment queues, lab reports, and autograder results. Prepare scores and comments in the tools you already use, then let the helper handle repetitive form entry. Instructors can use it too; you stay in control of grading and publication.

🔄

Class Navigation & Progress

Start here or rewind to the beginning. Partial CSVs are supported: students outside your file are skipped and counted separately as Outside CSV. Completion tracks only imported rows.

📝

Grade & Feedback Together

Fill Overall Grade and Overall Feedback from your spreadsheet, including multiline comments. Individual rubric scores and unrelated editors are left alone.

⚡

Fast Skip for Existing Matches

Skip published or previously verified evaluations when the grade and supplied feedback match. A difference or a confirmation dialog pauses the run for your review.

⚠️

Smart Unsubmitted Handling

Keep the student's name or ID and leave the score empty to skip without filling or saving. Zero is a real grade; completely empty lines are ignored. Outside-CSV students are skipped separately, not marked unsubmitted. Conflicting or ambiguous identities pause the run.

🔒

Privacy-First Architecture

No tracking, analytics, direct network/API calls, or third-party uploads. The script operates Brightspace fields and buttons; Brightspace handles its own server communication.

🎵

Audio Completion Chime

A pleasant 4-note chime signals that every intended CSV row is accounted for. Review the progress counts, including Outside CSV, and drafts before publishing results in Brightspace.

How It Works: 3 Simple Steps

1

Install a Userscript Extension

Install Violentmonkey (recommended) or Tampermonkey (alternative). Follow the extension prompts to permit userscripts in your browser.

2

Install the Userscript

Open the Greasy Fork listing, click Install this script, and confirm Install in your extension. Keep only one copy enabled. You can also use the source file with the manual installation steps.

3

Open Brightspace & Start Cruising

Open one student's assignment evaluation, not the class list. Use 📁 Load Gradebook CSV and check the preview. Verify one unpublished submission with Fill Current → Save Draft before starting 🚀 Auto-Cruise (or Alt + A).

Why Start with a CSV File?

Keep reviewing work and entering it into the LMS as separate steps. Prepare grades and feedback in Excel, Google Sheets, or your autograder, then import a CSV copy for the helper to enter through Brightspace's normal interface.

📊

Workflow 1: Brightspace Export

Export OrgDefinedId, first and last names, and only the target grade item from Brightspace Grades. Keep the exact exported column heading and ID values.

📑

Workflow 2: Excel / Google Sheets

Create a three-column sheet: student, score, reason. Leave scores blank only for explicitly unsubmitted rows; completely empty lines are ignored. Then save a CSV UTF-8 copy.

🐍

Workflow 3: Python / Autograder

TAs running Jupyter notebooks or Python test suites can write results directly to a grades.csv with a single loop.

Supported CSV Formats

Both formats can fill scores and overall feedback. These fictional examples are out of 100; use the correct points for your assignment. Feedback is ordinary text, not HTML.

Keyboard Shortcuts

Shortcut Action Description
Alt + A Toggle Auto-Cruise Starts continuous automated grading or pauses execution
Alt + S Emergency Stop Stops further automated actions; does not undo requests already sent
Alt + H Rewind to First Rapidly rewinds back to Student #1 in the class roster
Alt + F Fill Current Fills grade and feedback without clicking Save Draft or navigating
Alt + → Next Student Navigates to the next student in the iterator
Alt + ← Previous Student Navigates to the previous student in the iterator

Frequently Asked Questions (FAQ)

How do I import grades and feedback from CSV into Brightspace?

Install the helper, open an individual assignment evaluation, and load a CSV with student names or IDs, scores, and written feedback. Check the preview and verify one unpublished submission first. The helper fills Overall Grade and Overall Feedback through the evaluation page; it is separate from Brightspace's native Grades Import tool.

Can TAs bulk enter assignment feedback in D2L?

Yes, with permission to evaluate the assignment and supported page controls. Each CSV row can carry a different student's personalized comment. Use manual controls for a few entries or Auto-Cruise for your reviewed rows. The helper does not grant extra permissions or publish results.

Does this work with Excel, Google Sheets, or autograder results?

Yes. Save reviewed results as a CSV UTF-8 file with the supported columns, then load it in the helper. You still decide the scores and feedback: this is a data-entry helper, not an AI grader.

Does this work with my university's Brightspace domain?
It recognizes Brightspace page paths on standard and custom school domains. It is designed for the English-language Consistent Evaluation layout; an unfamiliar layout may pause the helper.
Will students see feedback immediately?
The helper clicks Save Draft, not Publish or Update. Review drafts and publish separately through Brightspace. Check the course's Grades configuration and the student view when confirming what has been released.
How is student privacy protected (FERPA / GDPR considerations)?
The script has no direct network/API calls, tracking, or third-party uploads. It interacts with the Brightspace page, which handles sending grades. Imported CSV data and progress stay in browser storage under your school's website. Reset Cache clears the helper's current-assignment data, not Brightspace grades.
What happens to already-published evaluations?
With fast skip enabled, matching grades and feedback are skipped. A mismatch pauses the helper; it does not click Update. An unsaved fill is not treated as an existing match.
